# Deployment

How to stand up a complete PQN Node from scratch and, optionally, federate it with other Nodes to form a PQN Network.

This section is the operator's runbook: it walks through installing `pqn-node`, pulling in `pqn-hardware`, configuring instruments, starting the Router and Hardware Providers, launching the Node API, deploying the GUI, and pointing everything at the right addresses. It also covers the network-side configuration needed for two-Node Experiments.
